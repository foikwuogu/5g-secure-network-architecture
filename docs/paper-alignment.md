# Paper Alignment

Primary reference: David Olufemi, Ayodeji Olutosin Ejiade, Friday Ogochukwu Ikwuogu, Phebe E. Olufemi, and Deligent Bobie-Ansah, “Securing Software-Defined Networks (SDN) Against Emerging Cyber Threats in 5G and Future Networks – A Comprehensive Review,” IJERT, Vol. 14, Issue 02, February 2025, DOI 10.17577/IJERTV14IS020102.

The paper discusses SDN control-plane centralization, OpenFlow/interface exposure, network slicing and slice hopping, edge computing, APTs, DDoS, ML anomaly detection, blockchain/integrity, Zero Trust, in-band telemetry, quantum-resistant cryptography, adaptive/self-healing systems, and scalability/performance tradeoffs. This project maps those themes to a synthetic laboratory: redundant controllers; slice models and slice-hopping scenarios; edge nodes; DDoS/MITM/APT/controller scenarios; a tamper-evident flow-rule digest ledger; Zero Trust scores; telemetry visibility; PQC readiness; adaptive mitigation; and latency-overhead metrics.

Where the paper advocates a technology without providing a production implementation specification, this repository models the concept rather than claiming production deployment. The ML component is represented as a research-ready security telemetry/risk layer rather than training on live malicious traffic.
