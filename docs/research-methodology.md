# Research Methodology

Research question: how can layered security controls improve resilience of SDN-enabled 5G networks while managing latency and scalability?

Scenarios: baseline, DDoS/control-plane saturation, MITM, slice hopping, cross-slice exposure, edge compromise, APT lateral movement, controller compromise, adaptive mitigation.

Measures: composite risk, risk reduction, mitigation effectiveness, controller availability, slice isolation, telemetry visibility, PQC readiness, latency overhead.

The composite risk score is an experimental construct, not an industry-standard metric. Publication-quality experiments should use multiple random seeds/intensities, explicit baselines, sensitivity analysis and confidence intervals.
